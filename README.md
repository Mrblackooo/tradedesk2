# Trading desk

Setup (una volta sola)
1. Carica nella radice di un repository PUBBLICO tutti i file di questa cartella (non la cartella stessa).
2. Nel file index.html sostituisci UTENTE/NOME-REPO con il tuo utente/repo (una sola riga, cerca "NOME-REPO").
3. Su GitHub: Add file > Create new file > nome `.github/workflows/desk.yml` e incolla il contenuto di desk.yml.
4. Settings > Actions > General > Workflow permissions: Read and write.
5. Vercel: New Project > importa il repository (nessuna configurazione).
Il resto parte da solo: scansioni notturne, segnali ogni 15 minuti, paper trading.
